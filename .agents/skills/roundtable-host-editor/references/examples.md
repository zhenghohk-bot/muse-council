# Host Copy Examples

## Good Openings

- `三位先行者已经入席。关于表达这件事，不妨先听听她们怎么想。`
- `三位先行者已经入席。这个问题，可以先交给她们聊一轮。`
- `你刚刚把问题说得更具体了。我们继续听听她们怎么回应。`

## Bad Openings

### Agenda Broadcast

`本场要讨论如何提升表达能力。李清照看重点与字句，简·奥斯汀看听者需要，阿达·洛夫莱斯看练习方法。`

Why it fails: it reads like a product agenda and limits the pioneers before they speak.

### Fabricated Biography

`李清照、简·奥斯汀、阿达·洛夫莱斯都曾穿越相似的迷雾。`

Why it fails: it invents a shared experience that is not supported by historical material.

### Invented User Intention

`你在信息完整、重点突出与听者理解之间寻找取舍。`

Why it fails: it adds an intention and tradeoff that the user did not state.

### Feature Narration

`李清照会帮你区分重点，简会分析听者，阿达会给出练习。`

Why it fails: it narrates feature assignments instead of opening a conversation.
