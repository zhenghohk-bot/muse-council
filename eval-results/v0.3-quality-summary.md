# v0.3.0 对话质量小结

## 本轮目标

v0.3.0 把第一轮发言从统一回答模板升级为 Conversation Director 编排：系统根据用户问题和人物能力分配不同谈话动作、承接关系与新增贡献，并对重复、心理归因、来源经历、交锋质量、行动卡和金句卡做确定性检查。

## 验收结果

| 场景 | 分数 | 结果 | 主要验证 |
| --- | ---: | --- | --- |
| 朋友关系与边界 | 88 | 通过 | 三位人物视角可区分；承接不复述；交换结构与精神空间形成真实交锋；行动卡与金句可追溯 |
| 原因不明的晨间沉重 | 85 | 通过 | 零心理归因硬失败；启用原因未知受控模式；行动只观察时间、身体位置、外界干扰与变化 |

两次针对性验收均无 API 降级、无确定性硬失败。`npm run build` 与 `npm run check:harness` 通过。

## 评测方法

- 生成模型按真实产品阶段运行：读题、编排、主持人、逐位发言、交锋、行动卡与金句卡。
- 独立裁判模型从九个维度评分：读题准确、人物区分、对话推进、重复控制、贴题性、语言清晰、安全、行动卡、金句卡。
- 本地硬规则单独检查第一人称、句长、语义重复、承接关系、行动具体性、来源追溯和未确认心理原因。
- 裁判高分不覆盖产品安全原则；真实输出若仍越界，会进入合同测试并推动 Harness 修正。

## 已知边界

- 本轮没有在最终代码上重新跑完整六题批次；结论是两个高风险场景已通过针对性验收，不代表所有开放问题都达到同一分数。
- 原因未知受控模式优先可靠与克制，人物文学性会比普通圆桌低一些。
- 轻度词语重复和交锋深度仍可继续优化，但不阻塞 MVP 作品集展示。
